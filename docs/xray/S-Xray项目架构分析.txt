S-Xray 项目架构分析

  📊 项目概览

  项目名称: S-Xray - Xray-Core 全功能管理脚本代码规模: ~17,000 行 Shell 脚本代码架构模式: 模块化分层架构核心技术:
  Bash Script + Xray-Core + JSON数据存储

  ---
  🏗️ 整体架构设计

  1. 三层系统架构

  ┌─────────────────────────────────────────────┐
  │         用户交互层 (UI Layer)              │
  │  - 主菜单系统 (xray-manager.sh)           │
  │  - 子菜单导航 (10个功能模块)              │
  └─────────────────────────────────────────────┘
                      ↓
  ┌─────────────────────────────────────────────┐
  │       业务逻辑层 (Business Logic)          │
  │  - 18个功能模块 (modules/*.sh)            │
  │  - 配置生成器、用户管理、节点管理等       │
  └─────────────────────────────────────────────┘
                      ↓
  ┌─────────────────────────────────────────────┐
  │        数据存储层 (Data Layer)             │
  │  - JSON文件存储 (/usr/local/xray/data/)   │
  │  - Xray配置文件 (config.json)             │
  └─────────────────────────────────────────────┘

  📁 核心模块详解

  职责: 统一入口、模块加载、主菜单调度

  # 主菜单调度 (xray-manager.sh:1961-1988)

  2. 节点添加 (add_*_node系列函数)

      # 协议层: 选择协议(VLESS)
      # 传输层: 选择transport(TCP/WS/gRPC)
      # 加密层: 选择security(Reality/TLS/None)

      # 生成节点配置 → 保存到nodes.json
      # 自动绑定admin用户 → 保存到node_users.json
      # 生成分享链接
  }
  3. 分享链接生成
    - VLESS: vless://uuid@ip:port?...
    - VMess: Base64编码JSON
    - Trojan: trojan://password@ip:port?...
    - SS: ss://method:password@ip:port
  4. 端口检测 (check_port_exists)

  🔄 核心业务流程

  1. 快速部署流程 (VLESS + Reality)

  用户选择"快速搭建"
      ↓
  自动域名优选 (测试20+个域名的延迟)
      ↓
  生成Reality密钥对 (privateKey/publicKey)
      ↓
  创建节点配置 → 保存到nodes.json
      ↓
  绑定admin用户 → 保存到node_users.json
      ↓
  生成Xray配置 → config.json
      ↓
  重启Xray服务
      ↓
  生成分享链接
      ↓
  显示二维码 + 手动配置参数

  2. 用户订阅生成流程

  用户选择"生成订阅"
      ↓
  选择目标用户
      ↓
  选择订阅类型(Base64/Clash/SingBox)
      ↓
  从node_users.json查询该用户绑定的节点
      ↓
  从nodes.json获取节点详细配置
      ↓
  根据订阅类型生成内容:
    - Base64: 节点链接列表 → Base64编码
    - Clash: YAML格式代理配置
    - SingBox: JSON格式outbounds配置
      ↓
  保存到 subscriptions/目录
      ↓
  生成订阅URL: http://ip:port/path/to/subscription
      ↓
  保存订阅元数据(流量限制、有效期等)

  3. 配置生成流程 (核心逻辑)

  调用 generate_xray_config()
      ↓
  读取三个数据源:
    - nodes.json (所有节点)
    - users.json (所有用户)
    - node_users.json (绑定关系)
      ↓
  遍历每个节点:
      ├─ 获取端口、协议、传输、安全层配置
      ├─ 查询该端口绑定的用户UUID列表
      ├─ 从users.json查询用户详情(enabled=true)
      ├─ 根据协议生成clients配置:
      │   ├─ VLESS: {id, email, level, flow?}
      │   ├─ VMess: {id, email, level}
      │   └─ Trojan/SS: {password, email, level}
      ├─ 根据传输层生成streamSettings:
      │   ├─ TCP: tcpSettings
      │   ├─ WebSocket: wsSettings
      │   └─ gRPC: grpcSettings
      ├─ 根据安全层生成:
      │   ├─ Reality: realitySettings
      │   ├─ TLS: tlsSettings
      │   └─ None: 无
      └─ 组装成inbound对象
      ↓
  生成outbounds配置:
    ├─ direct (直连)
    ├─ block (拦截)
    ├─ api (管理API)
    └─ 用户自定义出站规则(如果节点绑定了outbound_tag)
      ↓
  生成routing规则 (geoip/geosite分流)
      ↓
  生成stats/api配置 (流量统计)
      ↓
  组装完整config.json
      ↓
  验证JSON格式 (jq验证)
      ↓
  原子性写入:
    config.json.tmp → 验证成功 → mv覆盖config.json
      ↓
  重启Xray服务
